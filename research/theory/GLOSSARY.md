# Working glossary

Version 0.1. These are project proposals, not official terminology for an established field.

| Term | Working use | Status or limitation |
|---|---|---|
| Narrative | Representation of connected events involving entities over time, with temporal and/or causal relations supporting an account of change | Requires boundary examples |
| Narrative representation | Selected structured features of a work, with evidence references | Deliberately incomplete |
| Narrative system | Specified narratives, agents, exposures, contexts, relations, and changes within a defined boundary | Boundary must be stated per study |
| Narrative agent | An entity producing, transmitting, interpreting, or responding to narratives | A model agent is not automatically a valid substitute for a person |
| Narrative event | Depicted or stated change involving an entity | Pilot codebook must refine |
| Observation | Directly locatable material in a source or recorded response | Can still contain measurement error |
| Interpretation | An attributed reading supported by stated evidence and context | May admit disagreement |
| Reception | Independently observed or reported response to exposure | Not inferred from content alone |
| Exposure | Recorded contact with a narrative, including timing and conditions | Availability does not prove exposure |
| HNA | Human Narrative Atlas, from document 1 | Candidate instrument |
| NDE | Narrative Dynamics Engine, from document 2 | Candidate future modeling layer |
| NSE | Narrative Systems Engineering, from document 3 | Provisional name with existing public uses |
| Narrative DNA | Historical source metaphor for a representation | Prefer precise encoding terminology |
| Narrative energy | Historical proposed composite | Unvalidated |
| Narrative entropy | Potential dispersion measure over a defined interpretation distribution | Requires categories, sampling, and estimator |
| Narrative inertia | Potential persistence or resistance-to-change measure | Requires longitudinal observations |
| Narrative digital twin | Source ambition for a representation of a work | Fidelity and coverage not established |
| Social digital twin | Source ambition for a model of a population | No validated implementation |
